# おみくじWebサイト

美しく現代的なデザインのおみくじWebサイトです。日本の伝統的なおみくじをモダンなWebアプリケーションとして再現しました。

## 特徴

### 🎋 デザイン
- **モダンで美しいUI**: グラデーションとアニメーションを活用
- **レスポンシブデザイン**: スマートフォンからデスクトップまで対応
- **日本的な要素**: 絵文字と色彩で和の雰囲気を演出

### ✨ 機能
- **6段階の運勢**: 大吉、中吉、小吉、吉、末吉、凶
- **詳細な占い結果**: 恋愛、仕事、健康、金運の4項目
- **アニメーション効果**: スムーズな画面遷移とローディング
- **シェア機能**: 結果をSNSやクリップボードでシェア
- **キーボード操作**: Enterキーでおみくじを引く

### 🎯 運勢の種類
- **大吉** (15%): 最高の運勢
- **中吉** (25%): とても良い運勢
- **小吉** (25%): 良い運勢
- **吉** (20%): 普通の運勢
- **末吉** (10%): やや注意が必要
- **凶** (5%): 慎重に行動すべき日

## 使い方

1. Webブラウザで `index.html` を開く
2. 「おみくじを引く」ボタンをクリック
3. 結果を確認
4. 「もう一度引く」で再度挑戦
5. 「結果をシェア」で友達と共有

## 技術仕様

- **HTML5**: セマンティックなマークアップ
- **CSS3**: Flexbox、Grid、アニメーション
- **JavaScript (ES6+)**: モダンなJavaScript機能
- **Web APIs**: Clipboard API、Web Share API対応
- **フォント**: Google Fonts (Noto Sans JP)

## ブラウザ対応

- Chrome 80+
- Firefox 75+
- Safari 13+
- Edge 80+

## カスタマイズ

### 運勢の追加・変更
`script.js` の `fortuneData` オブジェクトを編集することで、運勢の種類やメッセージをカスタマイズできます。

### デザインの変更
`style.css` でカラーテーマやアニメーションを自由に変更できます。
